03 / Projects

Selected work

RAG Copilot

A hybrid-retrieval assistant combining BM25 keyword search with ChromaDB dense retrieval (BAAI/bge-m3 embeddings) and cross-encoder reranking, orchestrated with LangChain LCEL. Migrated generation from Gemini to a self-hosted Qwen3-8B on Hugging Face, with retrieval and hallucination quality tracked through Ragas. Deployed on Render.

CHUNK_SIZE=500 · CHUNK_OVERLAP=75 · TOP_K=4 · TOP_N_RERANKED=2

Customer Support RAG Assistant

Built a customer-support question-answering assistant using a hybrid retrieval pipeline that combines BM25 sparse retrieval with ChromaDB vector search, followed by Cross-Encoder re-ranking for improved context selection. · Implemented the application with LangChain LCEL and Hugging Face BAAI/bge-m3 embeddings, with Groq openai/gpt-oss-20b used for response generation Evaluated the Customer Support RAG pipeline using Ragas across 4 metrics: Faithfulness (0.798), Answer Relevancy (0.632), Context Precision (0.783), and Context Recall (1.000). The evaluation showed strong retrieval coverage while identifying answer relevance and retrieval precision as key areas for further optimization.

CHUNK_SIZE=500 · CHUNK_OVERLAP=75 · TOP_K_DENSE = 4 · TOP_K_SPARSE = 4 · TOP_N_RERANKED = 3
